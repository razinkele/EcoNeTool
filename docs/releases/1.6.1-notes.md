
### Notes

- The deploy now uploads the offline trait database build script
  (`scripts/initialization/build_offline_trait_db.R`) and the small tracked files it reads (BIOTIC, MAREDAT,
  PTDB, ontology, BVOL, SpeciesEnriched and the external-traits stubs). Other `data/` content stays managed on
  the server. Before this, the server kept an old build script, so Rebuild Database built without the 1.5.3
  lock/temporary-file safety and without the 1.6.0 vocabulary stamp, and without BIOTIC/MAREDAT/PTDB.
- No trait codes change in this release. A production database already rebuilt with 1.6.0's build script needs
  no new rebuild.
