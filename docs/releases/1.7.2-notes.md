# EcoNeTool 1.7.2 - Startup Order

Released 2026-10-19.

### Fixed — app startup loads files once, in order

- **The default food web is now loaded once per app start instead of twice.** Shiny was automatically running
  `R/config.R` and `R/data_loading.R` before `app.R`, which then ran them again. Start-up is correspondingly
  faster; nothing else changes for users.
- **Start-up no longer depends on that hidden order.** Because the automatic pass ran `R/data_loading.R` before
  the shared helpers in `R/functions/validation_utils.R` were loaded, any use of those helpers while loading the
  default web stopped the app at start-up. `app.R` now controls the whole load order
  (`R/_disable_autoload.R`), and a test checks that `app.R` loads every top-level file in `R/`.

### Upgrade notes

- No configuration, data or database changes.
