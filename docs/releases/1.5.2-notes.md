
### Notes

- Harmonization settings are now **session-only**. Saving or resetting the server default requires an
  unlocked admin, and is refused when no admin password hash is configured.
- A server-default file that fails validation (for example an FS0 pattern that matches diet nouns) is
  rejected, with a warning on the tab, and the session uses the built-in defaults. After upgrading, an
  admin should unlock and click **Reset server default** once if that warning appears.
- Trait-cache entries now carry the harmonization config hash. Entries written by earlier versions have
  none and are re-looked-up on first use, so phylogenetic imputation may report "No close relatives
  found" until the cache refills.
