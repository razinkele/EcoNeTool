# EcoNeTool 1.7.9 - Conventions Guard

Released 2026-10-21.

### Fixed — failures are reported instead of hidden

- **Lookup and file-reader failures now reach the server log.** 33 error handlers that returned an empty result
  without a trace (Ecopath/EcoBase readers, the FishBase, SeaLifeBase, SHARK, BIOTIC, MAREDAT, PTDB and ontology
  trait lookups, WoRMS, rphylopars, the taxonomy APIs, the ML loader and the CSV reader) now raise a warning.
  Expected absences — a WoRMS timeout, a taxon without WoRMS attributes — stay quiet.
- **ML gap-filling no longer switches off silently.** The model check was still relative to the working directory,
  so ML imputation was skipped whenever R was not started from the repository root; a missing model file now warns.
- **ICES SAG lookups report the real error** ("no SAG assessment for …") instead of "object 'result' not found".
- **API retries back off as intended.** The retry helper waited the initial delay on every attempt.
- **No unused parallel workers at startup.** The app no longer starts four background R processes (about 1 GB) that
  nothing used; ending one user's session also reset that setup for everyone else.
- Three maintenance scripts that loaded the removed `trait_lookup.R` work again, and their error counters update.

### Added

- `tests/testthat/test-conventions-guard.R`: CI fails if an error handler hides a failure without a
  `# swallow-ok: <reason>` comment, or if `<<-` / `<-` is used the wrong way round in error handling.

### Upgrade notes

- No configuration, data or database changes.
