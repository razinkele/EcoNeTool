# EcoNeTool 1.7.3 - Safe Loaders

Released 2026-10-19.

### Security — uploaded and bundled files are checked before use

- **Food web `.Rdata` files** (the startup web, Data Import uploads and the Network Comparison examples) are loaded
  in isolation, and the file is refused if it holds anything besides the network (`net`), the species table
  (`info`) and the three helper functions bundled with the original Baltic web (`fluxind`, `plotfw`,
  `trophiclevels`). The refusal names the unexpected objects.
- **Metaweb `.rds` files** must be an EcoNeTool metaweb with species, interactions and metadata; anything else is
  refused with a message saying what is missing. All bundled metawebs pass.
- **The deprecated `config/api_keys.R` is no longer executed at startup.** Only plain key assignments are read
  (`API_KEYS$worms_key <- "..."` or `worms_key <- "..."`, for the known keys), and anything else in the file is
  ignored with a warning. Installs using `config/api_keys.json` are unaffected.

### Fixed — Network Comparison

- Links that exist only in Network B now show B's species names (previously A's spelling was used for species
  present in both webs).
- A failed comparison now logs a warning instead of silently showing an empty table.

### Upgrade notes

- No configuration, data or database changes. If an old `.Rdata` upload is now refused, re-save it with only
  `net` and `info`.
