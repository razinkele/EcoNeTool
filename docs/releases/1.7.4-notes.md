# EcoNeTool 1.7.4 - Trait Routing

Released 2026-10-20.

### Fixed — trait lookup

- **Copepods and ostracods now query MAREDAT.** WoRMS files them under Arthropoda, so they were routed only as
  benthic invertebrates and the zooplankton database was never asked. They now get MAREDAT in addition to the
  invertebrate sources. Other arthropods (crabs, amphipods, ...) are unchanged.
- **ML-predicted traits load regardless of the working directory.** The model file was looked up relative to the
  current directory, so outside the repo root the models were reported missing and ML traits silently dropped out.

### Fixed — tests

- `tests/test_uncertainty_app_integration.R` sourced the deleted monolithic `trait_lookup.R`; it now loads the
  split `R/functions/trait_lookup/` files.

### Known limitation

- Cladocera, Mysida and Euphausiacea are WoRMS orders, not classes, and still do not reach MAREDAT; routing them
  needs the taxonomic order passed to the router.

### Upgrade notes

- No configuration, data or database changes. No offline trait DB rebuild needed.
