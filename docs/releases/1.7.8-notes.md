# EcoNeTool 1.7.8 - Spatial State

Released 2026-10-20.

### Fixed — Spatial Analysis tab keeps only current results

- **Changing the study area or grid clears what was built on it.** A new or cleared study area clears the grid,
  local networks, metrics and habitat layers (announced as "Grid cleared: study area changed"); a new grid clears
  networks, metrics and the habitat overlay; new networks clear the metrics; a new habitat clip clears the overlay.
  Previously a new grid could show the previous run's metrics, because hexagon ids restart at HEX_0001. Uploaded
  species data is never cleared.
- **Habitat is loaded for your study area or grid only.** Enabling habitat with neither set is refused, instead of
  silently loading a fixed 1 x 1 degree Baltic tile. Coverage is re-checked before clipping, because the Ecopath tab
  can load habitat for a different extent.
- **Species uploads are validated.** Semicolon-separated files and decimal commas are read correctly; rows with a
  missing species or invalid lon/lat are dropped with a warning; swapped lon/lat columns are flagged. Bad
  coordinates no longer end the session.
- **The metrics table no longer comes up empty** when species richness (S) is not among the selected metrics.
- **Species with missing biomass stay in their hexagon** (counted for presence; a warning reports how many).
- **Overlaying habitat a second time works** (it failed with "replacement has 0 rows") and no longer overwrites the
  base grid.
- Loading a BBT study area restores the server's spherical-geometry (s2) setting even on error, instead of forcing it
  on for every session in the process.

### Upgrade notes

- No configuration, data or database changes. BBT.geojson and the EUSeaMap GDB are now found from the app root,
  whatever the working directory.
