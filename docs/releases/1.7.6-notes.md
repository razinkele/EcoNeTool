# EcoNeTool 1.7.6 - Fish Habitat

Released 2026-10-20.

### Fixed — fish environmental position (EP)

- **Flatfish, gobies and sculpins are epibenthic (EP3) again.** FishBase describes them as "demersal" (on *or near*
  the bottom), which was read as benthopelagic (EP2) before the per-order fish rules were consulted. When habitat
  text says EP2 and the order rule says otherwise, the order rule now decides. Herring ("benthopelagic" in
  FishBase) follows the pelagic Clupeiformes rule (EP1).
- Specific habitat text still decides: a pelagic goby stays pelagic, garfish stays pelagic, and cod stays
  benthopelagic, credited to FishBase.
- **FishBase habitat is always used for fish and credited ahead of WoRMS.** It was skipped whenever WoRMS supplied
  habitat text first. WoRMS currently lists no functional group for fish, so this guards against future changes.

### Upgrade notes

- Cached trait lookups are refreshed on first use (lookup revision 4), so fish EP codes are recomputed.
- No configuration or data changes. The offline trait DB is not affected and needs no rebuild; fish whose EP comes
  from it keep their stored value.
